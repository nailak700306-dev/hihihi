# Site FD CONSULTING

Nouveau site vitrine de FD CONSULTING (Fabrice De Paz), reprenant tout le contenu de www.fd-consulting.net.

## Fichiers
- `index.html` : page d'accueil (approche, services, formations, méthode, à propos, témoignage, blog, contact)
- `article-techniques-de-vente-les-fondamentaux.html` : l'article du blog
- `assets/` : styles, script, typographies (Fraunces + Manrope, hébergées localement) et portrait
- `apercu-fd-consulting.html` : version autonome en un seul fichier, pour prévisualiser ou envoyer facilement
- `captures/` : captures d'écran

## Mettre en ligne
Site 100 % statique, sans dépendance : il suffit de déposer le dossier (sauf `apercu-fd-consulting.html` et `captures/`) chez n'importe quel hébergeur (Netlify, Vercel, OVH, o2switch, GitHub Pages…), puis de faire pointer le domaine fd-consulting.net dessus.

## Formulaire de contact
Le formulaire ouvre la messagerie du visiteur avec un e-mail pré-rempli vers fabricedepaz@gmail.com.
Pour recevoir les messages sans passer par la messagerie du visiteur, remplacer l'envoi par un service de formulaire (Formspree, Netlify Forms, etc.).
